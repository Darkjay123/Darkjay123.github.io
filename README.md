# ejc/scan

John Enechukwu's portfolio, built as a block explorer of everything he has shipped.

- **The chain**: each project is a block, SHA-256 hashed against the one before it, live in the browser.
- **The decoder**: crypto jargon translated to plain English and Nigerian Pidgin.
- **The mempool**: live public GitHub activity.
- **Sign a message**: a "safe signature" that only opens your email app.
- Press `/` anywhere for the terminal.

Single static file, no build step. Live at https://darkjay123.github.io
